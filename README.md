# Fashion Retail Sales Dashboard

## Project Overview

This project focuses on analyzing fashion retail sales data to generate actionable business insights. It includes customer segmentation, purchase behavior, product performance, and seasonal trends — all visualized in a clean and interactive dashboard.

The goal is to help businesses understand how their customers shop, what sells best, and when performance peaks throughout the year.
